# Sikkerhet

## Melde et sikkerhetsproblem

Send e-post til **<hey@jonm.cc>**. **Ikke** opprett et offentlig GitHub-issue
for sikkerhetsproblemer eller mistanke om at data er eksponert.

Ta gjerne med:

- hva du fant, og hvor (URL, endepunkt eller fil);
- hvordan det kan gjenskapes;
- om personopplysninger kan være berørt.

Du får svar så snart som mulig, normalt innen noen få virkedager.

## Personopplysninger

Ressursen behandler en begrenset mengde personopplysninger: tilbakemeldinger
fra besøkende (e-post, rolle, kommentar og en saltet hash av IP-adressen), som
beskrevet i [README.md › Data og personvern](README.md#data-og-personvern).
**Rapporter som gjelder brukerdata, behandles som hastesaker** og prioriteres
foran alt annet arbeid i prosjektet.

## Omfang

Gjelder koden i dette repoet og den deployede ressursen (Cloudflare Pages-
nettstedet og API-workeren). Innhold fra WHOs ICD-11 API eies og driftes av
WHO; problemer der meldes til WHO.

---

*English:* please report security issues or suspected data exposure privately
to <hey@jonm.cc>, not as a public issue. Reports involving user data
(feedback submissions) are treated as urgent.
