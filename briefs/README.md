# Session Briefs

Timestamped snapshots of Claude Code working sessions, written by the `session-brief` skill at the end of each session.

## What's here

- `YYYY-MM-DD-HH-MM.md` — one file per session. Generated by `/session-brief`. (Descriptive names are fine too — any `.md` here except this file and `reviewed.md` is a brief.)
- `reviewed.md` — running list of briefs the `find-skills` skill has already scanned. Don't edit by hand.

## Consumers

- `find-skills` — weekly cross-repo scan for repetition patterns worth turning into skills. It runs from `deepcut-foundation` and scans this directory as one of six brief corpora; its cursor commits land here directly on `main`.

## Format

Each brief has YAML frontmatter (`session_start`, `session_end`, `repo`, `pr_numbers`, `tags`) and body sections for tasks, repeated prompts, outputs, and friction. See `deepcut-foundation/operations/skills/session-brief/SKILL.md` for the schema.
